♛ Honest gaps

Signals we cannot measure at $0 yet — listed so nobody fills them with imagination.

  • Dashboard pageviews
    GitHub Pages serves no analytics; the traffic API covers repos, not the dashboard page itself.
    Cheapest fix: Ship a $0 client-side pageview beacon to a CWI endpoint (needs a receiver build).
  • X post metrics
    X is login-walled with no $0 API path for post-level metrics.
    Cheapest fix: Manual X Analytics export by Black, transcribed into results.json.
  • Gumroad sales
    Gumroad product is unpublished; no API key wired into the publish script.
    Cheapest fix: Wire a Gumroad API key into the publish script once the product is live.
  • MCP caller identity (first tool call)
    agent-deck-mcp v1.1.0 (shipped 2026-09-17) writes per-invocation receipts locally + supports an opt-in beacon — but the beacon receiver is not deployed yet, so no server-side T2 evidence exists.
    Cheapest fix: Deploy beacon-worker.js to Cloudflare (needs Black's account, ~5 min, $0); then set AGENT_DECK_BEACON_URL on installs.
  • Click-through
    No UTM/referral capture on outbound CTAs.
    Cheapest fix: UTM-tagged links + a referral log in results.json.
  • Human vs bot in repo traffic
    The traffic API exposes no user-agent/referrer breakdown.
    Cheapest fix: Pages-side beacon + README links so real human clicks become measurable.
