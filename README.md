# cwi-results — CWI Results Dashboard

Every verified CWI result, accumulated as it happens. Live page: https://cumulativewebinc.github.io/cwi-results/

## Truth-label discipline
- **LIVE** = verified real data, checked against a source, with a receipt.
- **MEASURED** = real API numbers (e.g. GitHub traffic) that may include bots — never claimed as human interest.
- **GAP** = unmeasured at $0. Shown as "—", never as a number.
- **TARGET** = a goal, not a result. Proposed targets are pending owner sign-off.

## Files
- `index.html` — the dashboard (regenerated by the publisher every 30 min).
- `results.json` — machine-readable, schema `cwi.results/1.0`.
- `brand/cwi-logo.jpg` — official CWI logo badge.

## Publisher
`~/workspace/results-dashboard/publish-results.js` (workspace only, never public). Reads the gear ledger, the consolidated gear registry, the GitHub traffic API, and the Moltbook post API. A failed source becomes a gap note — never a zero, never a guess. No secrets in this repo, ever.
